# Drag Specialties Dropship Ecommerce — Feasibility Project

Unrelated subproject, parked inside the moms-recipes repo as a scratch workspace
(this repo has nothing to do with the topic — it's just the cloud sandbox that

## Background

Kyle's brother works at a Harley-Davidson dealership near Appleton/Hamilton, WI.
He described a friend's operation — **Route 43 Motorsports** (Sheboygan, WI),
which runs the consumer storefront **43moto.com** — that appears to sell parts
online and drop-ship them directly from a distributor's warehouse, sourced from
**Drag Specialties** (dragspecialties.com), a large powersports parts
distributor. The brother believes Drag Specialties' API is "open" enough to
build an ecommerce/dropship business on top of it.

Goal of this phase: research whether that's true before designing anything.

See `RESEARCH.md` for findings.
